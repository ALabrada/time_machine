# History Lens

[![RuStore](https://img.shields.io/badge/RuStore-available-blue)](https://www.rustore.ru/catalog/app/com.fakegem.historylens)

**Package:** `com.fakegem.historylens`

History Lens lets you discover historical photographs and recreate them to compare past and present.

## Features

- **Discover historical photos** near your location using augmented reality or browse them on a map
- **Create replicas** by photographing how the same location looks today
- **Visual alignment** tools to line up historical and current photos before shooting
- **Import external photos** and align them precisely within the app
- **Save and compare** your replicas anytime
- **Share** your work on RePhotos or in-app social feeds

Historical photos and their geolocation data are sourced from publicly available online databases, including PastVu, RePhotos, Historypin, SepiaTown, and others.

## Getting Started

This is a Flutter project. To build and run the app:

1. Ensure you have Flutter installed
2. Clone the repository
3. Run `flutter pub get`
4. Run `flutter run`

## Permissions

The app may request access to:

- **Location** – precise location for finding nearby historical photos
- **Photos & Videos** – for capturing and importing photo comparisons

## Data Sources

The app aggregates historical photographs from public databases such as:

- [PastVu](https://pastvu.com)
- [RePhotos](https://re.photos)
- [Historypin](https://www.historypin.org)
- [SepiaTown](https://www.sepiatown.com)
- And others
